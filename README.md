# 하루 스도쿠

광고 없이 오프라인에서 이용하는 모바일 우선 스도쿠 PWA입니다. 초급·중급·고급·마스터 각 100문제를 순서대로 풉니다.

## 실행

별도 패키지 설치 없이 정적 서버에서 실행합니다.

```sh
cd sudoku
python3 -m http.server 4173
```

브라우저에서 `http://localhost:4173`을 엽니다. 처음 접속할 때 모든 문제를 내려받고, 이후에는 서비스 워커가 파일을 저장해 오프라인에서도 실행됩니다. 설치 기능은 HTTPS 또는 localhost에서 사용할 수 있습니다.

## 문제 데이터

`data/puzzles.json`에 400문제와 해답을 포함했습니다. 각 문제는 생성 시 해답이 하나인지 확인합니다. 문제를 다시 만들려면 `python3 scripts/generate_puzzles.py`를 실행합니다. 난이도는 시작 숫자 개수와 기본 풀이(단일 후보·숨은 단일 후보)로 풀리는 정도를 함께 기준으로 삼습니다. 고급과 마스터의 실제 체감 난이도는 사람의 풀이 검수를 거치지 않았습니다.

진행 기록은 기기의 브라우저 `localStorage`에 저장됩니다. 다른 기기와 동기화하지 않습니다.
